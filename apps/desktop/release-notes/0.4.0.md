## What's new in 0.4.0

**Figma's layout and names:** the editor now looks and reads like Figma's.
- A **floating toolbar** at the bottom of the canvas with Figma's tool slots (Move, Region, Shape, Creation, Type and Code tools), **Actions** (Ctrl+K), and a **Draw / Design / Motion / Dev Mode** switch.
- A **navigation rail** (File, Assets, Variables, Plugins) and the **Main menu** behind the logo, with File, Edit, View, Object, Text, Arrange, Vector, Plugins, Preferences, Libraries and Help.
- The Design tab in Figma's sections: **Position**, **Layout** (with Flow), **Appearance**, **Typography** and the new **Selection colors**.
- Figma's names and shortcuts throughout (for example Layout guides on Shift+G, Ungroup on Ctrl+Backspace, Zoom to 100% on Ctrl+0); the old shortcuts still work.

**New commands:** Copy and paste properties, Pick color, Select matching layers, Select inverse, Rotate, **Flip horizontal / vertical**, Remove fill or stroke, Swap fill and stroke, Tidy up, Pack, Distribute by edge, Round to pixel, page and frame stepping, Paste here, and **Convert to frame / section** (also from the type dropdown in the panel header).

**Layout:** **Grid** auto layout (columns, rows and gaps) and **Lock aspect ratio**.

**View:** **Outlines**, **Pixel preview** (Ctrl+Shift+P), a pixel grid when zoomed in, and Show slices.

**Motion:** a **Transform** section and keyframe buttons beside each property, Position shown as the layer's centre, an Add keyframe button on the timeline, and **audio** that plays with the timeline and is mixed into MP4 and WebM exports.

**Dev Mode:** **Ready for dev**, the **Measurement** tool (Shift+M), a Code / List view of layer properties, and **Compare changes** for a layer against an earlier version (account files).

**Fixed:** the timeline's buttons are visible again, and the toolbar no longer covers the Help button in narrow windows.

Flips, grid layouts and audio are new to 0.4.0: 0.3.0 opens these files but shows flipped layers unflipped, grids unlaid-out and no audio, so update to 0.4.0.
