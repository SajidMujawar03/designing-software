## What's new in 0.3.0

**Motion (beta):** animate frames on a timeline, as in Figma Motion.
- Keyframes on position, size, rotation, scale, opacity, corner radius, colours, stroke and blur, with auto-keyframe.
- Easing presets, custom Bézier curves and springs.
- Preset animations and styles (fade, slide, scale, blur, spin, pulse, shake, bounce), including text that animates by character, word or line.
- Animated component instances you can stagger.
- Export as MP4, WebM, GIF, Lottie, dotLottie or animated SVG.
- Copy the animation as CSS or JSON from Inspect, and play it in prototypes.

**Drawing:**
- **Draw mode** with brushes and the pencil.
- **Stroke width profiles** and variable width.
- **Vector edit actions:** lasso, bend, cut, eraser and paint.
- **Shape builder** for joining or subtracting overlapping shapes.
- **Text on a path.**

**Layout and hand-off:**
- **Sections, slices and the scale tool.**
- **Code snippets and annotations.**
- **Spec documents and live code layers.**

**Everyday:**
- **Arrows:** arrowheads and the arrow tool.
- **View:** settings (pixel grid snapping, cursors, minimize or hide UI, nudge amount), and an export background option for pages.
- **Panels:** quick action tabs, find and replace, and layer thumbnails.

**Fixed:** opening a local file no longer adds an extra empty page.

Files that use these features open view-only in 0.2.1 and earlier, so update to 0.3.0 to edit them.
